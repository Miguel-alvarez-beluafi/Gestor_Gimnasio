# Libreta de ejercicios
Esta app tiene como objetivo ayudar a llevar un registro de las sesiones de entrenamiento en gimnasios.  
También, si da tiempo, me gustaría implementar un registro de deportistas del gimnasio.  
Voy a usar una base de datos SQLite.
Voy a crear las siguientes vistas (según me dé tiempo serán funcionales o no):
+ Nueva sesión.
+ Última sesión.
+ Ficha de usuario.
+ Elegir usuario.
+ Registrar usuario.
